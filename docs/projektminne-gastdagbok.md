# Gästens första dagboksmening

- Startsidan öppnar gästeditorn via `/dagbok?action=new`. Editorn fokuserar och rullar fram skrivfältet. Tidigare utkast kan återupptas med **Fortsätt där jag var**.
- Det märkta sömnexemplet ligger direkt efter introduktionen. Publika länkar använder **Återblick** och går till `/framsteg`. Den egna återblicken kräver konto och anteckningar som användaren har sparat.
- **Chatta med AI** går till `/chat` med OpenAI-information vid valet och samtycke i chatten. **Logga in för att checka in** går via `/login?redirect=/dashboard/kvallsstugan`.
